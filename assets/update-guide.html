氚云代码重大更新使用指南

本版本开始，多个氚云应用统一放在“氚云代码”目录中管理。

为什么会看到这个提示？
您当前操作的应用可能仍然使用旧版目录结构，或者“氚云代码”目录下还没有统一的 .h3token 文件。 本版本不再从应用目录读取 Token。
1 重新构建项目结构
  1. 在 VSCode 中打开需要保存氚云代码的工作区文件夹。
  2. 按 Ctrl+Shift+P 打开命令面板。
  3. 执行“从氚云构建项目”。
  4. 输入应用编码、企业引擎编码和最新的 h3_token。
  5. 等待构建完成。工具会自动创建“氚云代码”目录，并把应用放在该目录下。
提示: 本版本不自动迁移旧项目。请重新执行一次“从氚云构建项目”，使用新方案生成项目结构。
更新后的目录结构
工作区/
└── 氚云代码/
    ├── .h3token
    ├── .gitignore
    └── 应用名称(axxxxx)/
        ├── cmax.json
        └── 表单名称(fxxxxx)/
2 以后如何同步应用
  1. 在资源管理器中展开“氚云代码”目录。
  2. 右键点击其中的应用目录，例如“应用名称(axxxxx)”。
  3. 选择“从氚云同步”。
  4. 工具会从“氚云代码/.h3token”读取 Token，并只提交当前应用的 Git 变更。
3 Token 和 Git 管理变化

.h3token 统一保存在“氚云代码”目录，不再放在每个应用目录中。

.gitignore 和 Git 仓库也统一放在“氚云代码”目录中，多个应用共用一个 Git 仓库。

注意: 请不要把 .h3token 提交到公开代码仓库。
4 多个应用如何更新 Token

右键点击“氚云代码”目录，选择“更新氚云 Token”，输入一次最新 Token 即可更新所有应用共用的 Token。

5 旧项目注意事项

本版本不自动迁移旧项目目录。如果应用仍在工作区根目录或其他旧目录中，请按照本指南重新构建一次。

重新构建完成并确认新应用可以正常同步后，再根据需要清理旧应用目录。
